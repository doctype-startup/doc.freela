# DOC.FREELA

Protótipo progressivo do CRM, iniciado pelo menu lateral com base nas capturas do DGFlow fornecidas pela proprietária do projeto.

Esta versão inclui a navegação visual, grupos expansíveis, seleção de páginas e menu responsivo. O conteúdo interno das páginas ainda depende das próximas referências e não contém dados reais nem integração com o CRM original.

Abra `dist/index.html` para visualizar localmente. O projeto é publicado pelo Sites.
